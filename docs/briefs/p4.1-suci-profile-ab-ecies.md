# Build Brief — P4.1: SUCI Profile A/B (ECIES) de-concealment

> Self-contained brief for Codex. The **charter wins on any conflict**
> (`docs/experience-charter.md`). When in doubt, do less and flag it. This is the
> P4.1 task in `docs/next-phases-plan.md` — the #1 protocol gap before testing
> against real UEs/basebands.

## Mission (one paragraph)
Today QCore only accepts **null-scheme** SUCI (the easy simulator case): the
subscriber's MSIN travels in the clear. Real devices conceal the SUCI with **ECIES**
(TS 33.501 Annex C) — **Profile A** (Curve25519) or **Profile B** (secp256r1) — so a
real UE/baseband cannot register against QCore at all. Your job: implement SUCI
de-concealment for Profiles A and B at the **SIDF (UDM)**, vector-validated against
the TS 33.501 Annex C test data, wired so a concealed SUCI completes 5G registration.
Crypto-first: get the de-concealment vector test green **before** wiring anything.

## Read first, in this order
1. `AGENTS.md` and `CLAUDE.md` (root) — evidence rules, Docker-only build/test,
   trust rule, §11 scope, the dist-embed-race rule for any dashboard touch.
2. `docs/briefs/auts-sqn-resync.md` — the prior crypto brief; same shape/discipline.
3. TS 33.501 **Annex C** (ECIES profiles) + **Annex C.4** (test data). The scheme

## How SUCI flows today (verified — reuse, don't rebuild)
- **NAS decode:** `pkg/nas5g/messages.go:75` `DecodeSUCI(data)` → `SUCI` struct
  (`pkg/nas5g/nas5g.go:215`): `{PLMN[3], RoutingIndicator[2], ProtectionScheme uint8,
  HomeNetworkPKID uint8, MSIN []byte}`. For a concealed SUCI, the **scheme output**
  (eph-pubkey‖ciphertext‖MAC) currently lands in `MSIN` as raw bytes.
- **AMF (no change needed for pass-through):** `pkg/amf/nas.go:798` `suciToString`
  already returns `"suci-" + hex.EncodeToString(mobileID)` for a **non-null** scheme
  (only null scheme is de-concealed locally via `nullSchemeSUCItoSUPI`,
  `pkg/amf/nas.go:821`). So the **full SUCI IE hex already reaches AUSF→UDM** as
  `suci-<hex>`. **Do not move de-concealment into the AMF** — keep it at the SIDF.
- **UDM (the SIDF — this is where you work):** `pkg/udm/udm.go:156` `parseIMSISupi(supi)`
  currently **rejects** anything not prefixed `imsi-` ("only imsi-<IMSI> SUPIs are
  supported"). It's called from `pkg/udm/ueau.go:93` and `:116` (auth + resync paths)
  and `pkg/udm/udm.go:55`. This reject is exactly where a concealed SUCI dies today.
- **Diagnostics already name the gap** (`pkg/diag/reconcile.go`,
  `pkg/diag/registration.go`: "null-scheme SUCI only", "schemes 1 and 2 not yet
  implemented"). Update these once shipped. `pkg/events/event.go` already has a
  `Scheme` field for telemetry.

## What to build

### 1. Crypto package — `pkg/suci` (de-risk FIRST)
A new `pkg/suci` (so UDM doesn't import `pkg/nas5g`; share SUCI parsing if useful).
Implement **ECIES de-concealment** per TS 33.501 Annex C — all from Go stdlib, **no
new dependencies, no CGO**:
- ECDH: `crypto/ecdh` — `ecdh.X25519()` (Profile A), `ecdh.P256()` (Profile B).
- KDF: **ANSI X9.63 KDF with SHA-256** (not HKDF) — `K = SHA256(Z ‖ counter(4B) ‖
  SharedInfo)` concatenated until enough bytes; split into AES-128 key, ICB (IV), and
  MAC key per Annex C.3.
- Cipher: AES-128 in **CTR** mode (`crypto/aes` + `crypto/cipher`).
- MAC: **HMAC-SHA-256 truncated to 64 bits** (8-byte tag); verify in constant time
  (`hmac.Equal`).
- Profile B point compression (secp256r1) per Annex C.
Signature sketch: `Deconceal(scheme uint8, hnPriv *ecdh.PrivateKey, schemeOutput []byte)
(msin []byte, err error)` returning the recovered MSIN (then BCD→digits).

**Acceptance gate #1 (stop here if it fails):** `pkg/suci/suci_test.go` reproduces the
**TS 33.501 Annex C.4** Profile A **and** Profile B test vectors — given the spec's HN
private key, eph. public key, ciphertext and MAC, your `Deconceal` recovers the spec's
plaintext MSIN and the MAC verifies. **Get this one test green before wiring anything.**
If the vectors don't match, stop and report — do not proceed.

### 2. Home-Network private-key config
The SIDF needs the HN **private** key(s), selected by `HomeNetworkPKID`. Add config
(verify the real shape against `pkg/config/config.go` + `config.example.yaml` before
referencing fields — do not invent keys): e.g. a list of `{id, scheme, privateKeyHex}`
under the UDM/subscriber config. **Never log or echo private keys.** Provide a demo HN
keypair so the bundled UERANSIM profile can use Profile A end-to-end (see §4).

### 3. Wire de-concealment into the SIDF (UDM)
Where `parseIMSISupi` / `generateAuthData` (`pkg/udm/ueau.go`, `pkg/udm/udm.go:55`)
receive a `suci-<hex>`: parse the SUCI IE (reuse `nas5g.DecodeSUCI` semantics or a
`pkg/suci` parser), and if `ProtectionScheme != 0`, select the HN private key by
`HomeNetworkPKID`, call `pkg/suci.Deconceal`, recover the MSIN, build `imsi-<MCC><MNC><MSIN>`,
then continue exactly as the null-scheme path does. Null scheme and `imsi-` inputs must
keep working unchanged (back-compat). On MAC failure / unknown PKID / unsupported scheme,
return a clean problem response (mirror the existing `MAC_S_FAILURE`→403 style in
`pkg/udm/ueau.go`), not a 500.

### 4. Validation (the payoff)
- **In-process E2E test:** a concealed Profile-A SUCI (built in the test from the demo
  HN public key) drives registration to completion, equivalent to the null-scheme path.
- **Interop (tier-3, the real proof):** configure the bundled UERANSIM `ue.yaml`
  (`deployments/docker/ueransim-config/ue.yaml`) with `protectionScheme: 1`,
  `homeNetworkPublicKey: <demo pub>`, `homeNetworkPublicKeyId: <id>`, give QCore the
  matching demo **private** key, and prove registration completes with a **concealed**
  SUCI on the `ueransim-interop` gate (extend `.github/workflows/ueransim-interop.yml`
  the way `scripts/ci/ueransim-sqn-resync.sh` did — assert an ordered, real log
  sequence and print a new `::notice::SUCI PROFILE A PASS`). Capture the GitHub run ID.

## Rules (non-negotiable)
- **Build/test only in Docker** (no host Go):
  `docker run --rm -v "$PWD":/src -w /src -v qcore-gomod:/go/pkg/mod golang:1.23 \
    sh -c "go build ./... && go vet ./... && go test ./..."` (`-race` final pass).
  Any dashboard/diag UI touch: build the frontend (`tsc --noEmit` + `vite`) **first and
  separately** (dist embed race), then the Go build.
- **Zero new deps / zero CGO** — ECIES is entirely Go stdlib. If you think you need a
  dependency, stop and flag it (you don't).
- **Trust rule:** nothing is ✅ until build+vet+test are green **and** the Annex C
  vector test passes; interop claims require a cited GitHub run ID. "Passes our own
  test" ≠ "validated against a real external UE."
- **No fabrication:** verify every symbol/path/config field by reading the file or `rg`
  before referencing it. Never invent test vectors — copy them from TS 33.501 Annex C.4.
- **Never log secrets** (HN private keys, Ki/OPc). One feature branch
  `codex/suci-profile-ab`; **new commits only, never amend, never force-push**; use a
  `git worktree` if another agent shares the tree.
- **Scope (charter §11):** Profiles A and B only (the 3GPP-defined ECIES profiles). No
  custom schemes, no carrier-scale key management, no HSM. 4G/EPC SUCI is out of scope.
