# QCore outreach assets

Generated launch/demo media belongs here.

The README demo is generated by:

```bash
make demo-recording
```

The command records a real dashboard run and writes:

- `qcore-demo.gif` — README-friendly animation, hard-capped below 10 MB.
- `qcore-demo.mp4` — higher-quality recording for posts/releases.
- `qcore-demo-evidence.json` — capture metadata and visible storyboard beats.
- `qcore-demo-*.png` — screenshots for launch posts.

Do not hand-edit these generated files or replace them with staged/mock footage.
